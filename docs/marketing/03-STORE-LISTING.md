## ✅ استبيان تصنيف المحتوى (أجب بصدق — الأخطاء تُرفض)

| السؤال | الجواب الصحيح لحالتك |
|---|---|
| هل يحتوي التطبيق على محتوى ينشئه المستخدمون؟ | **نعم** (شات + أفاتار مستخدم) |
| هل يتشارك المستخدمون موقعهم؟ | لا |
| هل يحتوي التطبيق على محتوى عنيف/جنسي؟ | لا (توجد ضوابط وحظر) |
| هل يتم الشراء داخل التطبيق؟ | نعم (بعد إضافة Play Billing) |
| **الفئة العمرية المطلوبة** | **13+** (مع بوابة عمر) — لا تختر «مناسب للأطفال» |

## ✅ استبيان أمان البيانات (Data safety) — الإجابات الجاهزة

| البند | الجواب |
|---|---|
| البيانات المجمّعة | البريد الإلكتروني (تسجيل الدخول) · معرّف المستخدم · محتوى ينشئه المستخدم (رسائل وصور) |
| هل تُشارك مع طرف ثالث؟ | **لا** (إن أضفت Supabase كمزوّد استضافة فقط — ليس «بيعاً») |
| التشفير أثناء النقل | نعم (HTTPS) |
| يمكن طلب حذف البيانات | نعم (حذف الحساب داخل التطبيق + البريد) |
| بيانات مالية | لا (المدفوعات عبر جوجل بلاي) |
| الموقع الجغرافي | لا |

> ⚠️ **أعلن فقط ما هو صحيح فعلاً.** الإجابات غير الدقيقة سبب شائع لرفض التطبيقات أو حذفها بعد النشر.
> **وأهم سطر قبل النشر:** إن أضفت إعلانات مكافأة لاحقاً، عدّل بطاقة «الإعلانات» و«أمان البيانات» قبل التحديث — لا بعده.
