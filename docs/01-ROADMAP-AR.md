## مبدأ العمل معك (خطوة بخطوة)

كل مرحلة أسلّمها هكذا:
1. **الكود** في المودع (يمكنك فتحه من هاتفك أو حاسوبك).
2. **خطوة تنفيذ واحدة** عليك إن لزمت (مثل: نفّذ ملف SQL، أو الصق المفتاحين).
3. **تحقق سريع** (ماذا يجب أن تراه على الشاشة).
4. ثم أنتقل للمرحلة التالية.

لن أكتب كل شيء دفعة واحدة حتى لا تضيع وأنت تختبر؛ وإن أردت تسريع الوتيرة قل لي **«تسريع»** وأنفّذ مرحلتين في المرة.

## المرحلة 3 — أساس التطبيق (قيد العمل الآن)

- [x] Gradle (Kotlin DSL) + Kotlin 2.0.21 + Compose BOM + R8/proguard
- [x] Manifest: أذونات، `supportsRtl`، اتجاه بورتريه، رابط عميق `addonstation://recovery`، منع النسخ الاحتياطي للجلسة
- [x] أيقونة التطبيق (بالمقاسات الخمسة من مشروعك الأصلي)
- [x] خط البكسل `pixel_regular.ttf` (Press Start 2P بترخيص OFL — يغطي التركية) + تجاوز للعربية/الروسية/الصينية
- [x] ملفات النصوص: `values/` (الإنجليزية = اللغة الأساسية) + `values-ar/` + `values-pt/`
- [x] بقية اللغات: `values-es` `values-ru` `values-zh` `values-fr` `values-tr` (420 مفتاحاً متطابقاً × 8 — يتحقق منها `tools/check_i18n.py`)
- [x] الثيم الكامل: الألوان الـ12، التدرجات (app_bg)، الحواف (16/22/13)، الحدود، أزرار متدرجة
- [x] الخطوط: عناوين بكسل 22/18/14/9 بتباعد حروف، نص نظام 11.5–13 (وتحويل تلقائي للنصوص المدعومة)
- [x] تبديل اللغة الفوري + RTL/LTR حسب اللغة (`LocaleManager` + `AppPrefs`)
- [x] الشريط العلوي (شعار + عنوان الصفحة + شريحة AC) والشريط السفلي (5 عناصر + زر المنزل المرتفع 58dp)
- [x] الـ Splash السينمائي: سماء + خطوط مسح + 8 جسيمات + DREAM IT / BUILD IT / CREATE IT + شعار العلامة
- [x] الشاشة الرئيسية كاملة (التحية الزمنية، بطاقة الحالة، البحث، الإجراءات السريعة، الخطط، المميز، الأحدث، المبدعون، كن مبدعاً، الحصريات، الموصى به، التذييل)
- [x] شاشات المصادقة الأربع: دخول/تسجيل/نسيت/إعادة ضبط + رسائل الحالة المطلوبة

> **تبقّى في المرحلة 3 (تحسين اختياري):** خطا `pixel_bold` و`pixel_label` غير مربوطين بالتطبيق حالياً لأن نسخة Silkscreen تنقصها أحرف `İ ı Ş ş Ğ ğ` — التطبيق يستخدم `pixel_regular` فقط للعناوين البكسلية.

## المرحلة 4 — الشبكة والبيانات

- [x] عميل HTTP (OkHttp) لثلاث واجهات Supabase: `auth/v1` (GoTrue) · `rest/v1` (PostgREST + RPC) · `storage/v1`

- [x] حالة عامة واحدة (`AppState` + `AppContainer`) تُشارَك بين الشاشات

## المرحلة 5–12 (بالترتيب الملزم من الوثائق)

- **المتجر:** تبويبان (إضافات/عوالم)، بحث، ترتيب (الأحدث/الأكثر تحميلاً/مشاهدة/تقييماً)، شبكة حتى 60 عنصراً، الحالة الفارغة «لا توجد نتائج».
- **تفاصيل المحتوى:** غلاف 195dp، شارات الخطة، الإحصاءات، «بواسطة {creator}»، الوصف، أزرار التحميل/الحفظ، المحتوى المشابه، وكل الرسائل المذكورة حرفياً (بما فيها «🪙 {price} AC · فتح بالـ AC» و«🔒 يتطلب Epic 💎»).
- **تيار التحميل:** فحص الملف → تسجيل الدخول → خصم AC → `record_content_download` → رابط موقّع 60 ثانية → تنزيل داخل تخزين التطبيق.
- **الشات:** قائمة الغرف (13 في تصنيفين مع مؤشرات غير المقروء والمنشن)، شاشة الدردشة بكل قواعد ديسكورد (تجميع 5 دقائق، فاصل التاريخ، فاصل «جديد»، الردود بخط منحني، المنشنات كشرائح زرقاء، التفاعلات، الملصقات 150dp، الصور 260dp، مشغّل الصوت/الفيديو، الإعلانات، رسائل النظام، «🚫 تم إخفاء هذه الرسالة»، التمرير الذكي + زر «↓ رسائل جديدة»، 100 رسالة + تحميل أقدم، «يكتب الآن…»).
- **شريط الكتابة:** ➕ (صورة/وسائط) + حقل (4 أسطر) + 😊 (48 إيموجي + 5 حزم ملصقات) + زر إرسال أخضر، مع حدود 500 حرف، منع الروابط والبيانات الشخصية، 4MB للصور و100MB للوسائط.
- **بطاقة العضو (Bottom Sheet) وملفه الكامل:** الغلاف 100dp/140dp، الأفاتار 80dp، شرائح الرتب والمستوى والأداة، أزرار الرسالة/الصداقة/الملف، لوحة المعلومات، الإحصاءات، أدوار ملوّنة.
- **الملف الشخصي:** 4 تبويبات (نبذة/محتواي/مفضلتي/خطتي) + 4 بلاطات إحصاء + تعديل الملف + ترقية.
- **الإعدادات:** الحساب، اللغة (8 لغات مع تطبيق فوري)، المظهر (داكن/فاتح)، التنبيهات، الدعم، حول التطبيق، حذف الحساب.
- **محفظة AC:** الرصيد، الشرح، مهام الكسب مع زر مطالبة، سجل المعاملات.
- **الإشعارات:** طلبات الصداقة (قبول/رفض)، المنشن، الرد، نشاط الموضوع، شارة «جديد».
- **الخطط والدفع:** شاشة الاشتراكات، CHECKOUT، «طلبك جاهز»، رفع الإيصال، «طلباتي» بالحالات الخمس.
- **الإدارة:** شريط سفلي من 5 (الرئيسية/المحتوى/المدفوعات/الإشراف/المزيد) + 10 شاشات (نظرة عامة، محتوى، مدفوعات، إشراف، أصول، إعدادات، AC، تِيبس المبدعين، طلبات المبدعين، مراجعة محتوى المبدعين) + شاشة **الدردشة** الإدارية (إدارة الغرف، الصلاحيات، الإعلانات، تأديب المستخدمين، قائمة البلاغات، سجل العمليات، الفلترة التلقائية، محرر القواعد).
- **المبدعون:** الدليل، البروفايل، الدعم (Tips)، نموذج التقديم، Creator Studio، الحصريات.
- **القفل الصارم للوحة الإدارة:** زر «لوحة» يظهر فقط لـ `role == admin`، وأي محاولة لغير المدير تُقابل بـ **«غير مسموح — حسابك ليس Admin»**.

## ملاحظات تنفيذية ملزمة

1. **لا يوجد بناء APK** حتى تطلب ذلك صراحةً (سيُبنى لاحقاً عبر Android Studio أو GitHub Actions — `docs/05-BUILD-APK-AR.md`).
2. كل نص في التطبيق موجود في **الـ8 لغات**؛ ملف `tools/check_i18n.py` يفشل إذا نقص مفتاح في أي لغة.
3. التركية: LTR + `uppercase(Locale("tr"))` + تحية زمنية «Günaydın / İyi akşamlar» + خط بديل للأحرف `İ ı Ş ş Ğ ğ`.
4. العربية أولاً في المحتوى وRTL، والإنجليزية هي لغة التطبيق الافتراضية حسب نص الوثيقة.
5. لا مفاتيح سرية داخل التطبيق — `anon key` فقط، وكل عملية حساسة عبر دوال الخادم.
