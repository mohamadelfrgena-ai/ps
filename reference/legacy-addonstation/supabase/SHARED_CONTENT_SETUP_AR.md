# ربط بيانات AddonStation بين الموقع والتطبيق

الموقع وتطبيق الهاتف يستخدمان نفس جدول المحتوى:

```text
public.content_items
```

## الإعداد مرة واحدة

من داخل **Supabase Dashboard → SQL Editor**:

1. تأكد من تشغيل ملفات الأساس:
   - `000-foundation.sql`
   - `content-schema.sql`
   - `creator-program.sql` عند استخدام برنامج المبدعين
2. شغّل الملف:

```text
SHARED_BACKEND_SYNC.sql
```

3. شغّل نظام العملات الآمن:

```text
ac-economy.sql
```

هذا الملف يقوم بـ:

- إضافة `category` و`version` للمحتوى القديم والجديد.
- إعطاء الموقع والتطبيق صلاحية قراءة المحتوى المنشور.
- تجهيز تخزين الصور وملفات الإضافات والعوالم.
- تجهيز دليل المبدعين والمتابعة.
- إبقاء الملفات والمحتوى في نفس المصدر، بدون إنشاء قاعدة بيانات ثانية.

بعد ذلك، أي محتوى منشور من لوحة الإدارة أو برنامج المبدعين سيظهر في الموقع والتطبيق عند فتح الصفحة أو تحديثها.

> لا تستخدم مفتاح Service Role داخل الموقع أو التطبيق. تشغيل SQL يتم من SQL Editor فقط.
