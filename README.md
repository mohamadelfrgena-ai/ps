# AddonStation Mobile 🎮

تطبيق أندرويد أصلي (Kotlin + Jetpack Compose) لمتجر إضافات وعوالم **Minecraft Bedrock** للاعبي PS4/PS5 — مع شات مجتمعي مستوحى من **Discord**، اشتراكات ودفع، ومحفظة AC، ولوحة إدارة كاملة **للأدمن فقط**.

> هذا المشروع يُبنى بترتيب صارم حسب ثلاث وثائق ملزمة موجودة في `docs/specs/`:
> 1. `AddonStation-Design-Spec.md` — التصميم الكامل (ألوان، خطوط، شاشات، سلوك)
> 2. `AddonStation-Chat-Admin-Spec.md` — الشات بأسلوب ديسكورد + لوحة الإدارة + اللغة التركية
> 3. `AddonStation-Plans-Payments-Spec.md` — الخطط والاشتراكات وتدفق الدفع والحماية

## تشغيل التحقق من اللغات

```bash
python3 tools/check_i18n.py        # 🟢 كل اللغات مكتملة ومتطابقة (420 × 8)
python3 tools/check_kotlin_refs.py # ✓ كل مراجع R.string والمستودعات والأيقونات سليمة
python3 tools/check_calls.py       # ✓ كل نداءات دوال Compose تطابق تعريفاتها
python3 tools/check_symbols.py     # ✓ لا مراجع إلى أصناف/دوال غير موجودة
python3 tools/build_all_in_one_sql.py    # يبني supabase/00_ALL_IN_ONE.sql
python3 tools/upload_seed_assets.py --url ... --key sb_secret_...   # رفع 311 أصلاً
```

## الأمان (مُلخّص)

- التطبيق يحمل **المفتاح العام فقط** (`anon key`) — لا مفاتيح خدمة داخل التطبيق أبداً.
- كل عملية حساسة (تفعيل خطة، منح AC، حذف رسالة، تأكيد دفع) تمرّ بدوال `SECURITY DEFINER` تتحقق من الجلسة والدور.
- الخطة المنتهية = `free` لحظياً، والملفات المدفوعة بروابط موقّعة **60 ثانية**.
- لوحة الإدارة تظهر لـ `role = admin` فقط، وأي محاولة أخرى تُرفض على الخادم لا في الواجهة فقط.
