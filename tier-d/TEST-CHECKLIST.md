## المجموعة C — المظهر الحقيقي للاعب (المعيار الأساسي)

| البند | الشرط | كيف تتحقق | النتيجة |
|---|---|---|---|
| C1 | المظهر يتغيّر فعلًا | اختر «Azure Mechanic»، اضغط F5؛ **شخصيتك أنت** تتغيّر في العالم | NOT RUN |
| C2 | ليس دمية ولا معاينة | التغيير على لاعبك الحقيقي، لا على كيان آخر ولا في شاشة معاينة | NOT RUN |
| C3 | كل المظاهر تعمل | جرّب الأربعة واحدًا واحدًا؛ كل زر يعطي لونه الصحيح | NOT RUN |
| C4 | الرجوع للسكن الأصلي | اختر «Use my own skin»؛ يعود سكنك أنت تمامًا | NOT RUN |
| C5 | الأنيميشن سليم | امشِ، اقرفص، اسبح، اضرب، اركب؛ لا تشوّه ولا تجمّد في الحركة | NOT RUN |
| C6 | المنظور الأول سليم | يدك في المنظور الأول تحمل نفس المظهر المختار | NOT RUN |
| C7 | الدرع لا يتعارض | البس درعًا كاملًا فوق المظهر؛ يظهر الدرع بشكل طبيعي | NOT RUN |

## ماذا تسجّل عند الفشل

إن لم يتغيّر المظهر، أرسل:

1. صورة شاشة لشخصيتك بعد الاختيار (F5، مع واجهة اللعبة ظاهرة).
2. صورة سجل المحتوى: Settings ← Creator ← Content Log GUI، وأي سطر فيه `skinmenu`.
3. نص رسالة الدردشة التي ظهرت بعد الاختيار بالضبط.
4. رقم إصدار اللعبة.

هذه المعلومات تحدّد أي قناة فشلت، وهل نحتاج الانتقال إلى خطة الزي القابل للارتداء
(Attachable) بدل متحكّم الرسم.
