# Skin Lab — Tier B four-skin experiment

**Status:** source prototype built; structural, mocked-script, archive, and browser checks passed. **Windows Bedrock, Android Bedrock, and PS4 hardware tests are NOT RUN.** This is not a player-skin equip tool and not a PS4 compatibility claim.

## The boundary that matters

| Layer | What it does | What it does not do |
|---|---|---|
| Browser interface | Rotates a software humanoid preview and shows the 64×64 atlas | Does not run Minecraft or change a player |
| RP + BP prototype | Opens an ActionForm and textures a separate `tierb:skin_preview` mannequin | Does **not** equip the selected texture on the local player |
| Optional manual skin pack | Provides the same four PNGs as a separate `skin_pack` for a Windows/Android Dressing Room control test | Is not part of the RP+BP, not an automatic script equip, and not evidence of PS4 support |

The documented stable Script API surface inspected here has no arbitrary-PNG setter for the local human player. A pre-release GameTest `SimulatedPlayer.setSkin` exists, but it targets simulated test players and Persona-style data, not this local-player PNG workflow. See [RESEARCH.md](RESEARCH.md).

## Build and test

Requires Node.js 22.12+ and npm. Dependencies are pinned in `package-lock.json`.

```sh
cd tier-b
npm ci
npm test
npm run serve
```

Open the served URL printed by the command (default port 4174), or open `index.html` directly for the offline browser preview. The browser smoke test is separate because it needs the sandbox browser tooling:

```sh
LD_LIBRARY_PATH=/tmp/al2023/lib:/tmp node tools/browser-smoke.mjs
```

`BROWSER_TOOLS` can point at a directory containing `playwright-core` and `@sparticuz/chromium`; `BASE_URL` can override the default local URL. Those tools are not needed to build or use the packs.

## In-game preview command

In a disposable local world with both packs active and cheats enabled:

```text
/scriptevent tierb:preview
```

Choose a skin button. A separate mannequin appears two blocks ahead if the space is clear. Its name begins `PREVIEW ONLY`. Use **Remove preview** to delete it. Leaving the world also attempts cleanup. The actual player skin is never assigned by this code.
