# AddonStation — تطبيق Kotlin

هذا تطبيق أندرويد أصلي بـ Kotlin و Jetpack Compose. ليس موقعًا داخل WebView.

يحتفظ بنفس حسابات الموقع، المتجر، العوالم، الحصريات، المجتمع والشات، الملصقات، الصنّاع، طلب الانضمام، استوديو الصانع، محفظة AC، الإشعارات، الإعدادات، الدعم، والاشتراكات. البيانات تبقى على نفس مشروع Supabase.

## البناء

1. افتح مجلد `android` في Android Studio.
2. انتظر تحميل Gradle و Android SDK.
3. شغّل التطبيق على جوال أو محاكي، أو ابنِ APK من:
   `Build > Build Bundle(s) / APK(s) > Build APK(s)`

الحد الأدنى أندرويد 8 (API 26). الواجهة عربية من اليمين لليسار، ويمكن تغيير اللغة والمظهر من الإعدادات.
