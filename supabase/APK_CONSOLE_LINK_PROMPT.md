# مهمة جاهزة للنسخ — نظام ربط جهاز PlayStation بالكود (تطبيق APK)

> انسخ كل ما بين الخطين والصقه للذكاء الاصطناعي المتولّي تطبيق الأندرويد.

---

## المطلوب: إضافة نظام ربط جهاز PlayStation بالكود إلى تطبيق الأندرويد (APK)

نظام ربط الأجهزة **موجود بالكامل ومنفَّذ في Supabase** (نفس قاعدة بيانات تطبيق السوني — **لا تعد إنشاء أي جدول أو دالة**، فقط استدعها). تطبيق السوني يعرض كوداً من 6 خانات على الشاشة، وعلى تطبيق الهاتف أن يتيح للمستخدم **إدخال هذا الكود لربط جهازه بحسابه**.

### أضف في التطبيق:

**1) زر «ربط جهاز PlayStation» (Link a console)** — في شاشة الإعدادات أو قسم الحساب، يفتح شاشة إدخال الكود.

**2) شاشة إدخال الكود:**
- حقل إدخال واحد للكود (6 خانات): حوّل الأحرف تلقائياً إلى الكبيرة، واسمح بالمسافة والشرطة ثم نظّفهما (`K7P 4QX` و`K7p-4qx` كلاهما يعمل).
- أبجدية الكود الحقيقية (لا توجد فيها 0/O/1/I — استخدمها للتحقق المبكر في الواجهة): `23456789ABCDEFGHJKLMNPQRSTUVWXYZ`
- زر «ربط» + حالة تحميل أثناء الاستدعاء.
- يجب أن يكون المستخدم **مسجّلاً دخوله**؛ إن لم يكن → اعرض واجهة تطلب تسجيل الدخول أولاً.

**3) استدعاء Supabase RPC (بتوكن المستخدم المسجّل):**

```
POST {SUPABASE_URL}/rest/v1/rpc/claim_console_link_code
apikey: {SUPABASE_ANON_KEY}
Authorization: Bearer {access_token الخاص بجلسة المستخدم}
Content-Type: application/json

{
  "p_code": "K7P4QX",
  "p_access_token": "{access_token الحالي}",
  "p_refresh_token": "{refresh_token الحالي}"
}
```

- `p_code` (مطلوب): الكود كما أدخله المستخدم — الخادم ينظّفه ويكبّره.
- `p_access_token` و`p_refresh_token` (اختياريان لكن **مرّرهما**): توكنات جلسة المستخدم الحالية في Supabase — ليصل الجلسة نفسها إلى جهاز السوني عند الربط.
- إذا كان لديك عميل supabase جاهز (supabase-flutter / supabase-dart / supabase-js): `supabase.rpc('claim_console_link_code', params: {'p_code': ..., 'p_access_token': ..., 'p_refresh_token': ...})`

**4) رسائل النتيجة (الخادم يرجع jsonb فيه `ok` ثم `message` عند الخطأ):**

| الاستجابة | التصرف في الواجهة |
|---|---|
| `{ok:true, platform, device_name}` | نجاح: «تم ربط جهازك ✓» + اسم الجهاز، ثم انتقل لقائمة الأجهزة |
| `{ok:false, message:'sign_in_required'}` | اطلب تسجيل الدخول أولاً |
| `{ok:false, message:'invalid_code'}` | «الكود غير صالح — يجب أن يكون 6 خانات» |
| `{ok:false, message:'code_not_found'}` | «الكود غير صحيح» |
| `{ok:false, message:'code_expired'}` | «الكود منتهي أو مستخدم مسبقاً — اطلب كوداً جديداً من السوني» |

ملاحظة مهمة: الكود **صالح 10 دقائق ويعمل مرة واحدة فقط** — أي إعادة استخدام ترجع `code_expired`.

**5) شاشة/قسم «الأجهزة المرتبطة» (My linked consoles):**
- اعرض صفوف الجدول `linked_consoles` الخاصة بالمستخدم فقط (RLS جاهز — يرجع صفوفه تلقائياً):
  - `device_name` (اسم الجهاز)، `platform` (ps4/ps5)، `created_at` (تاريخ الربط)، `last_seen_at` (آخر ظهور)
- الترتيب: الأحدث أولاً (`created_at` تنازلي).
- زر **«إلغاء الربط»** بجانب كل جهاز = **حذف صفه** من `linked_consoles` (سياسة الحذف جاهزة) مع تأكيد قبل الحذف.
- اسحب للتحديث (pull-to-refresh)، وحدّث القائمة فور نجاح الربط.

### ممنوع:
- ❌ لا تنشئ جدولاً أو دالة أو Policy جديدة — كل شيء موجود ومنفَّذ.
- ❌ لا تقرأ جدول `console_link_codes` مباشرة (RLS مغلق على العملاء) — استخدم الدوال فقط.
- ❌ لا تولّد الكود من الهاتف: التوليد والاستطلاع من طرف السوني فقط.

### معايير القبول:
- [ ] إدخال `k7p 4qx` أو `K7P-4QX` يعمل وينظّف إلى `K7P4QX`.
- [ ] بعد النجاح: تأكيد باسم الجهاز + تحديث قائمة الأجهزة فوراً.
- [ ] كل رسالة خطأ تظهر بالعربية الواضحة حسب قيمة `message`.
- [ ] غير مسجّل الدخول → لا يُرسل الطلب أصلاً ويطلب تسجيل الدخول.
- [ ] إلغاء الربط يحذف الجهاز من القائمة (مع تأكيد) ويعمل عبر RLS فقط.

## مرجع تقني (لا تنسخه — للعلم فقط)

- `create_console_link_code(p_platform, p_device_name)` → يستدعيها **السوني** (anon): ترجع `{ok, code, formatted_code, poll_token, expires_at, expires_in_seconds}`.
- `poll_console_link_code(p_code, p_poll_token)` → يستدعيها **السوني** كل 3 ثوانٍ: `{ok, status: waiting|linked|expired|consumed|invalid}` وعند `linked` ترجع بيانات المستخدم + الجلسة **مرة واحدة فقط**.
- جدول `linked_consoles`: `id, user_id, platform, device_name, linked_code, last_seen_at, created_at`.
