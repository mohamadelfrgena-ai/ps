# Original demo assets

`signal_scout.png` and `lunar_courier.png` are tiny synthetic textures generated by `tools/make-examples.js` for this prototype. They are not copied from Bedrock-Skins, Minecraft, or Marketplace packs.

`skin-lab-demo.mcpack` is a structural example for Windows/mobile import testing. It is not a PS4 installer and does not bypass console skin restrictions.
